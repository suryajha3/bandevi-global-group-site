# Public Company Profile Preview

The Company Profile page now uses the published incorporation, GST and Udyam fields. A separate manual Preview action creates an inline public company profile, followed by an explicit Print / Save as PDF action. No file downloads, new tabs or print windows open automatically. The browser owns the printer/PDF destination choice.

The fixed public field list contains the legal name, CIN, incorporation date, GSTIN/effective date, Udyam number/date and recorded Micro classification for 2026–27, business address, three service descriptions, central business contacts and official verification links. The output is labelled “Public company information — not a quotation.” Record-review dates distinguish the supplied source documents from a current issuer lookup. No independent live registry or digital-signature validation is claimed.

The controller does not read visitor fields, cookies, storage, URL parameters, CRM records or uploaded documents. It has no network, analytics, messaging or record-saving operations. Private source certificates, personal identifiers, bank details, unsupported staffing/financial claims and customer results are excluded. The printable document is freshly constructed from the fixed public list, never cloned from arbitrary page contents. Changes to the visible preview invalidate Print until manual Refresh and review. Closing/cancelling printing clears the temporary paper and print marker; blocked or unavailable printing preserves the preview. Initialization is idempotent; keyboard focus, Escape, no-JavaScript fallback and responsive layouts are included.

Only the Company Profile page loads the new assets. Historical whole-file scope checks forward this exact approved page/renderer delta, and continue comparing every other public page, existing controller and private server file. CRM, sales ownership, proposals, messages, tasks, calendars and reply-watch reminders remain outside the release. No service restart is required for the public static files.
